## 2. Testziel & Ablauf der End-to-End Pipeline

Nachgewiesen wird die vollständige Funktionskette für die Analysefunktion `GOOGLE_MAPS_LOCATION_QUERY`:

```
[Google Maps Location / URL + User Question]
                │
                ▼
      [AnalysisRegistryImpl]  ---> (Findet LocationQuestionEngine)
                │
                ▼
     [LocationQuestionEngine]
                │
   ┌────────────┴────────────┐
   ▼                         ▼
[LocationQuestionPlanner]  [LocationQuestionCoordinator]
(Kategorienerkennung &     (Aggregiert Places API, Reviews,
 Source-Auswahllogik)       Wikipedia, Grounding-Flag)
   └────────────┬────────────┘
                ▼
     [BaseGeminiEngine]       ---> (Gemini API & Response-Parsing)
                │
                ▼
        [DomainSummary]        ---> (Validierte Ausgabe & Historie)
```

## 3. Testergebnisse der Kern-Testfälle

### Testfall 1: Restaurant (Stoßzeiten)
- **Input:** 
  - Location: Restaurant (*"Gasthaus zur Post"*, `https://maps.app.goo.gl/restaurant_sample`)
  - Nutzerfrage: *"Was sind typische Stoßzeiten und wann ist es ruhiger?"*
- **Ergebnisse Pipeline:**
  1. **Registry:** `AnalysisRegistryImpl` ordnet den Request der `LocationQuestionEngine` zu.
  2. **Planner:** Erkennt Kategorie `STOSSZEITEN`. Primäre Quellen: `REVIEWS`, `GOOGLE_MAPS_CONTEXT`. `requiresGrounding` = `false`.
  3. **Coordinator:** Aggregiert Ortstext, Öffnungszeiten und Erfahrungsberichte (Reviews).
  4. **Engine & Gemini:** `BaseGeminiEngine` verarbeitet den Prompt `F_GOOGLE_MAPS_LOCATION_CONTEXT.md` ohne unnötiges Grounding.
  5. **DomainSummary:** Valide Erzeugung des `DomainSummary`-Objekts mit Titeln, Kurzbeschreibung und präzisen Key Takeaways zu Auslastung & ruhigen Zeitfenstern.
- **Status:** `PASS`

## 4. Testergebnisse der Fehler- & Grenzfälle

| Fehlerfall | Verhalten in Pipeline | Ergebnis |
| :--- | :--- | :--- |
| **Ungültige Google Maps URL** | Planner/Coordinator nutzen Freitext-Fallback zur Standorterfassung. | `PASS` (Graziöser Fallback) |
| **Keine Location auflösbar** | `requiresGrounding` wird gesetzt; Gemini nutzt Live-Websuche. | `PASS` |
| **Keine Reviews vorhanden** | Fallback auf Orts-Metadaten & Enzyklopädie-Kontext ohne Absturz. | `PASS` |
| **Einzelne Quelle nicht verfügbar** | Coordinator führt resilienten Partial-Fetch aus; leere Quellen werden ignoriert. | `PASS` |
